## Goal

Run the exact pipeline the app uses, from a terminal, without Electron. This is how the pipeline is
built, debugged and evaluated (by you and by the AI agent) before any UI exists.

## Usage

```bash
npm run clip -- <video> --lang bn|en|hi [options]

  --projects-dir <dir>      default: ./.projects (git-ignored)
  --project <id>            reuse an existing project instead of creating one
  --to <stage>              stop after this stage (e.g. --to transcribe)
  --force <stage[,stage]>   rerun these stages
  --clips <n>               default 10
  --min <sec> --max <sec>   default 20 / 60
  --preset <id[,id]>        default youtube-shorts
  --llm <kind>:<model>      e.g. ollama:<model-name>, anthropic:<model-id>
  --llm-url <url>           base URL for ollama / openai-compatible
  --context <tokens>        LLM context size
  --transcriber <kind>      whisper-local | openai-compatible-transcription
  --whisper-model <name>    default from the language registry
  --replay-llm <dir>        replay recorded LLM responses (deterministic runs/tests)
  --json                    machine-readable progress lines
```

## Rules

- R1. Uses `createPipeline` with the same stages as the worker; only the injected dependencies
  differ (bins from `resources/bin/win-x64` or env `CLIPPER_BIN_DIR`; face detection stubbed until
  SPEC-080 provides a CLI path).
- R2. Keys from environment / `.env.local` (SPEC-110 R9). Never printed.
- R3. Ctrl+C aborts the run signal; the CLI waits for cleanup and exits 130.
- R4. Exit codes: 0 success, 1 stage failed, 2 bad arguments or missing binaries, 130 cancelled.
- R5. Prints one line per progress update (`[transcribe] 42% chunk 3/7`) or JSON lines with `--json`.
- R6. On success prints the project folder and the exported files.

## Acceptance criteria

M0:

- [ ] `npm run clip -- fixtures/en/short.mp4 --lang en` with zero stages registered creates a
      project folder with `project.json` and an empty manifest, exit 0.
- [x] Missing `--lang` or an unknown language exits 2 with a helpful message listing bn, en, hi.

M1:

- [ ] Full run on each language fixture exports clips.
- [ ] `--to transcribe` then a full run reuses the transcript (no second transcription).
- [ ] `--replay-llm` gives identical `candidates.json` across runs.
