# Caption fonts

Static Bold TTFs (SIL Open Font License), names must match `captionFont.file` in
`src/shared/languages.ts`:

| Language | Family | File |
|---|---|---|
| bn | Hind Siliguri | `HindSiliguri-Bold.ttf` |
| en | Montserrat | `Montserrat-ExtraBold.ttf` |
| hi | Hind | `Hind-Bold.ttf` |

All from Google Fonts. Add `OFL.txt` (the licence text) next to them. These are candidates — the
render test in SPEC-090 confirms them (conjuncts intact, Latin words in the same font).
